# Memory Game 🏎️🏁

Стильная игра на поиск пар на автомобильную тематику. Игрок переворачивает карточки с изображениями популярных суперкаров (Ferrari, Lamborghini, BMW и др.) и запоминает их расположение, чтобы найти все совпавшие пары за минимальное количество ходов.

Проект разработан в рамках учебного задания RS School.

## 🏎️ Особенности игры

- **Автомобильный сеттинг:** 8 уникальных парных карточек с суперкарами разных брендов и цветов, а также автомобильная рубашка карт.
- **Полная генерация на JS:** Вся HTML-разметка приложения создается динамически с помощью `document.createElement`, исходный `<body>` содержит только тег `<script>`.
- **Zero Libraries:** Чистый JavaScript (Vanilla JS), HTML5 и CSS3 без использования сторонних UI-библиотек или игровых фреймворков.
- **Таблица лидеров:** Топ-10 лучших результатов сохраняются в `localStorage` и не сбрасываются при перезагрузке страницы.

## 🛠️ Технологический стек

- HTML5
- CSS3
- Vanilla JavaScript

## 🎮 Правила игры

1. Игра начинается автоматически при загрузке страницы. На поле находятся **16 карточек** (8 пар суперкаров), разложенных рубашкой вверх в случайном порядке.
2. За один ход игрок может открыть **две карточки**.
3. Если карточки **совпали** — они остаются открытыми. Счётчик найденных пар увеличивается.
4. Если карточки **не совпали** — они демонстрируются игроку около 1 секунды, а затем автоматически закрываются. На время демонстрации поле блокируется для кликов.
5. Игра завершается, когда найдены все **8 пар**. После этого появляется модальное окно победы с результатом, а результат заносится в локальную Таблицу лидеров.
6. Кнопка **«Новая игра»** в хедере или в окне победы позволяет мгновенно перемешать карты и обнулить счетчики, отменяя текущий прогресс.

## 🚀 Локальный запуск

Для запуска проекта на вашем компьютере выполните следующие шаги:

1. **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/Maslovars/memory-game.git
    ```

2. **Перейдите в ветку проекта:**

    ```bash
    git checkout memory-game
    ```

3. **Запустите проект:**
   Поскольку проект написан на чистом JavaScript и не требует сборки, вы можете открыть файл `index.html` напрямую в браузере или использовать любой локальный сервер (например, расширение **Live Server** в VS Code).
